# Аудит безопасности. Проблемы текущей архитектуры в разрезе обращения с данными.

## Состояние покоя
1. Отсутствие шифрования персональных данных. Данные хранятся в открытом виде (plain text) в Excel файлах.
2. Excel не поддерживает должных механизмов защиты данные: доступ, сохранность, противодействие утере данных.

## Состояние передачи
1. Отсутствие шифрования персональных данных при передаче по сети.
2. Вероятно данные могут быть подвержены перехвату, т.к. отсутствует VPN (зашифрованный туннель) между участниками процесса обмена данными.

## Состояние использования
1. Отсутствие аудита доступа к данным.
2. Отсутствие валидации вносимых данных на уровне информационной системы.
3. Отсутствие политик (RBAC) доступа к данным. Данные хранятся на сетевых ресурсах без разделения доступа по ролям.
